3. Hosting der Website

Diese Website wird über GitHub Pages, einen Dienst von GitHub, Inc., bereitgestellt.

Beim Aufruf der Website können technisch erforderliche Verbindungsdaten verarbeitet werden. Dazu gehören insbesondere die IP-Adresse des verwendeten Geräts sowie weitere technische Informationen, die für die Auslieferung und Sicherheit der Website erforderlich sind.

GitHub dokumentiert, dass beim Besuch von GitHub-Pages-Websites die IP-Adresse der Besucher zu Sicherheitszwecken protokolliert und gespeichert wird.

Eine Verarbeitung von Daten ausserhalb der Schweiz, insbesondere in den USA, kann dabei nicht ausgeschlossen werden.

4. Kontaktaufnahme per E-Mail

Auf dieser Website besteht die Möglichkeit, ClearVision Consulting per E-Mail zu kontaktieren.

Wenn Sie per E-Mail Kontakt aufnehmen, werden die von Ihnen übermittelten Daten bearbeitet. Dazu können insbesondere gehören:

  • Name
  • E-Mail-Adresse
  • Betreff
  • Inhalt Ihrer Nachricht
  • freiwillig mitgeteilte weitere Kontaktdaten
  • technische E-Mail-Metadaten

Die E-Mail-Kommunikation erfolgt über Google Workspace.

Die Daten werden zur Bearbeitung Ihrer Anfrage, zur Kommunikation mit Ihnen sowie gegebenenfalls zur Vorbereitung oder Durchführung einer Geschäftsbeziehung verwendet.

Anfragen, aus denen keine Geschäftsbeziehung entsteht, werden grundsätzlich gelöscht, wenn sie für die Bearbeitung nicht mehr erforderlich sind. Als interne Orientierung gilt dabei eine Aufbewahrungsdauer von bis zu zwölf Monaten nach dem letzten relevanten Kontakt, sofern keine gesetzlichen oder geschäftlichen Gründe eine längere Aufbewahrung erforderlich machen.

5. Terminvereinbarung über Cal.com

Für die Online-Terminvereinbarung verwendet ClearVision Consulting den Dienst Cal.com der Cal.com, Inc., USA.

Auf der Seite „Erstgespräch / Strategie-Call“ ist ein Cal.com-Buchungskalender direkt in die Website eingebettet.

Bereits beim Aufruf dieser Seite wird eine Verbindung zu Cal.com hergestellt. Dabei können insbesondere technische Daten an Cal.com übermittelt werden, beispielsweise:

  • IP-Adresse
  • Browser- und Geräteinformationen
  • Spracheinstellungen
  • Zeitpunkt des Zugriffs
  • aufgerufene Seite
  • Referrer-Informationen, soweit vom Browser übermittelt

Cal.com kann zur Bereitstellung und Absicherung des Dienstes technisch erforderliche Cookies einsetzen.

Bei der Buchung eines Erstgesprächs werden folgende personenbezogene Angaben verwendet:

  • Name
  • E-Mail-Adresse

Zusätzlich können folgende Angaben freiwillig abgefragt werden:

  • Praxis beziehungsweise Unternehmen
  • gewünschter Unterstützungsbereich

Als Unterstützungsbereiche sind derzeit vorgesehen:

  • Alignertherapie
  • Klinische Planung
  • Teamtraining
  • Workflow-Optimierung
  • Allgemeiner Austausch

Es werden über die Terminbuchung ausdrücklich keine Patienten-, Gesundheits-, Diagnose- oder Behandlungsdaten benötigt oder vorgesehen.

Die Terminbuchung dient ausschliesslich der Organisation eines unverbindlichen Erstgesprächs beziehungsweise Strategie-Calls.

Nach der Buchung wird eine Buchungsbestätigung per E-Mail versendet.

Cal.com erklärt in seiner Datenschutzerklärung, dass der jeweilige Cal.com-Kunde bei Buchungen über dessen Konto für die Buchungsdaten verantwortlich ist und Cal.com diese Daten als Auftragsverarbeiter verarbeitet.

Cal.com ist ein Unternehmen mit Sitz in den USA. Daten können daher in den USA oder anderen Ländern verarbeitet werden. Cal.com gibt an, für internationale Datenübermittlungen geeignete Datenschutzmechanismen einzusetzen.

Die Verarbeitung erfolgt zur Terminverwaltung und zur Koordination des vereinbarten Gesprächs.

Google Meet wird als Bestandteil von Google Workspace verwendet.
